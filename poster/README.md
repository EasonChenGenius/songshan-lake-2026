# 看见不可见｜长图海报版

这是在交互终版 **v47** 基础上独立制作的静态长图排版，存放于 GitHub 分支 `poster/long-scroll`。原站与 `main` 分支保持不变。

## 内容与设计

- 五章报道、作者序言、三则采访问题与结语全部展开。
- 原网站轮播里的 **21 张照片**和 XbotPark 合影 **1 张**全部直接展示，共 **22 张现场图集照片**；此外包含人才活动主舞台、湖上画面静帧、立体湖区图等视觉元素。
- 不含 XbotPark 视频，也不使用轮播、滚动显现、自动播放或任何动画脚本。
- 照片不使用懒加载，适合浏览器截取整页长图。
- 采用深蓝、米白、暖金的编辑设计风格，明确区分真实现场照片和 AI 概念视觉。

## 本地查看和截长图

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/poster/`，推荐在桌面浏览器将页面宽度设为 **1440px**，等待图片加载完成。

Chrome 或 Edge：按 `F12` 打开开发者工具，再按 `Ctrl/Cmd + Shift + P`，输入 **Capture full size screenshot** 并执行。获得整页 PNG 后，可按需要裁剪成若干张海报图。

如需打印成 PDF，可使用浏览器打印功能，并勾选“背景图形”。

## 素材引用

`poster/index.html` 使用 `../dist/assets/` 中已经存在的图片。这个分支保留了原网站的 `dist/` 素材目录，因此无需复制图片，也不会影响交互终版。
